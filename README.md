# Nexus_IA — Documentação inicial do SaaS

Este pacote reúne documentos fictícios para demonstrar a base de conhecimento do **Nexus_IA**, uma plataforma SaaS de organização de projetos e tarefas para equipes.

## Documentos incluídos

1. `documentos/01_base_conhecimento.md` — visão geral do produto, recursos e orientações.
2. `documentos/02_faq_suporte.pdf` — perguntas frequentes e respostas de suporte.
3. `documentos/03_politica_privacidade.md` — política de privacidade demonstrativa.
4. `documentos/04_planos_precos.csv` — planos e preços fictícios em formato tabular.
5. `documentos/05_termos_de_uso.docx` — termos de uso demonstrativos.

6. `documentos/05_inventario_documental.csv` — inventário com categoria, caminho, versão, status, responsável e ingestão.
7. `documentos/06_plano_coleta_organizacao.md` — plano de mapeamento de fontes, curadoria, ownership, permissões e ingestão inicial.

## Aviso importante

O Nexus_IA e todos os dados comerciais deste pacote são fictícios e foram preparados para fins educacionais, prototipagem e testes de recuperação de informação (RAG). Os preços, prazos e regras não representam uma oferta real. A política de privacidade e os termos de uso são modelos ilustrativos, não constituem aconselhamento jurídico e precisam de revisão profissional antes de qualquer uso real.
